# EOS-Public

The public, employment-facing portfolio derived from a private personal engineering knowledge base. This repository is a **foundation, not a finished product** — it exists to be added to deliberately, over time, never by bulk import.

## What this is

A small number of real, verifiable engineering artifacts, plus the operating discipline behind how they were built — rewritten for a public audience rather than copied from their private source. See [`docs/engineering-operating-system/`](docs/engineering-operating-system/) for that discipline itself, and [`case-studies/`](case-studies/) for the artifacts.

## What this is not

Not a mirror of any private repository. Nothing here was migrated in bulk, and nothing will be. Every addition is reviewed individually against [`docs/PUBLICATION_BOUNDARY.md`](docs/PUBLICATION_BOUNDARY.md) before it lands here.
