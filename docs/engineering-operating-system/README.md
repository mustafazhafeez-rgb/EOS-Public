# Engineering Operating System (placeholder)

**Status: not yet written.** This folder will eventually hold a genericized write-up of the decision-making and planning discipline used to build every other project in this repository — separated deliberately from `standards/` (which holds *technical* standards) and `case-studies/` (which holds *narrative* write-ups of specific projects).

## What will go here

A rewritten, illustrated version of a real personal engineering-governance framework, covering:

- A decision-record pattern (what was found, what was produced, what was explicitly not done, and the result — before acting, not after)
- An epistemic-labeling discipline (separating a verified fact from a claim, an observation, an inference, and a genuine unknown)
- A planning standard (separating an objective from a proposed solution, and classifying a decision's reversibility and effect on future options before committing to it)
- A named practice for tracking what is *not yet* understood about a system that has already been built

## What will not go here

Any real instance of the private decision log this pattern was extracted from. Every example in this folder, once written, will be illustrative and clearly labeled as such — see [`../PUBLICATION_BOUNDARY.md`](../PUBLICATION_BOUNDARY.md) for why that distinction is load-bearing rather than a formality.
