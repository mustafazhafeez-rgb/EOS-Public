# EOS-Public

The public, employment-facing portfolio derived from a private personal engineering knowledge base. This repository is a **foundation, not a finished product.** It is added to deliberately, one reviewed item at a time, never by bulk import.

## What EOS is today

**EOS (Engineering Operating System)** is a personal system for running engineering and life projects with the same discipline used on hardware and vehicle systems: written decisions, version control, traceability, and an honest record of what isn't known yet.

**How the work actually gets done today:**
- **One human sets direction and makes every decision.**
- **AI assistants do bounded jobs.** One researches, drafts and maintains the repository. Another reviews architecture and reasoning. Each works through written handoffs stored in the repository, not through the human relaying messages.
- **The repository is the system of record.** If a conversation and the record disagree, the record wins.

**Where it's heading (direction, not a finished design):** a small, human-directed engineering practice, with clearer AI roles and more of the routine upkeep automated. That operating model is still being designed privately and isn't presented here as settled.
